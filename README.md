# Starbeak: Galactic Rebellion — Android APK Edition

Production-ready Unity (C#) codebase targeting **Android API 34+ (Android 14+)**, scalable
down to **API 29**. Native **1080x1920 portrait** with touchscreen virtual-joystick *or*
absolute-finger-tracking drag mechanics with LERP input interpolation.

Architecture: highly decoupled component-based design over persistent singletons, sized for
**200 active projectiles** and **50 screen entities** at a locked **60 FPS** with
zero post-warmup allocation.

> **Original IP.** This project was authored from scratch as `Starbeak: Galactic Rebellion`
> and shares no code, assets, or trademarks with any existing commercial title.

## 0. First run — one-click bootstrap

The repo ships code + sprites + build configuration. Scenes and prefabs are generated by an
Editor script so the serialized YAML is always schema-valid.

1. Open the project in **Unity 2022.3 LTS or newer** (2D + UGUI modules).
2. Run menu **`Starbeak > Build Project Content`** (shortcut `Ctrl+Shift+B`).
   This builds the **4 scenes**, the **7 prefabs**, wires every serialized reference, and
   registers the scenes in Build Settings (Boot first).
3. Run menu **`Starbeak > Validate References`** to confirm nothing is unassigned.
4. Press **Play** from the Boot scene, or **File > Build Settings > Build** for the APK.

Generated files (safe to regenerate any time — the builder overwrites them):

| Scene | Contents |
|---|---|
| `Assets/Scenes/Boot.unity` | All 8 `DontDestroyOnLoad` managers + `PlayerShip` + camera |
| `Assets/Scenes/MainMenu.unity` | Main menu canvas, resource bar, settings panel |
| `Assets/Scenes/SectorMap.unity` | Galaxy map canvas + `GraphContainer` |
| `Assets/Scenes/Gameplay.unity` | HUD canvas: hull/shield bars, resources, pause overlay |

| Prefab | Contents |
|---|---|
| `Assets/Prefabs/Projectile.prefab` | Player laser (`PlayerProjectile` layer) |
| `Assets/Prefabs/EnemyProjectile.prefab` | Egg (`EnemyProjectile` layer) |
| `Assets/Prefabs/Shrapnel.prefab` | Feather shrapnel (`EnemyProjectile` layer) |
| `Assets/Prefabs/Chicken.prefab` | Chicken entity (`Enemy` layer) |
| `Assets/Prefabs/HazardArea.prefab` | Napalm ground effect (`HazardArea` layer, trigger) |
| `Assets/Prefabs/NodeButton.prefab` | Map node button (UI) |
| `Assets/Prefabs/EdgeLine.prefab` | Map connector line (UI) |

Placeholder sprites live in `Assets/Sprites/` (generated procedurally). Replace them with
final art at any time — the builder re-links by name.

## 3. Key algorithms

### Procedural sector map
- Tier 0 = exactly **1 entry node**.
- Tiers 1–3 split into **2–4 branching paths** from a seeded `System.Random`.
- Tier 4 consolidates into exactly **1 mandatory Boss stronghold node** that receives an
  edge from every final-tier node.
- `ConnectAdjacentTiers()` guarantees every tier-n node has a forward link, then
  `EnsureNoOrphanedNodes()` adopts any zero-degree node so **no orphaned nodes exist**.
- `SectorNode` is a struct, so all edge creation routes through `Link()`/`Store()`, which
  writes the mutation back to **both** the list and the lookup (otherwise it is discarded).

### Flock Mind Matrix (`EnemyAIManager.RunFlockMindScan`)
- Tracks player coordinates every **0.25s** (`GameConstants.FlockScanInterval`).
- **Wide-spread detection:** if the player's spread angle **> 30°**, chickens collapse into
  horizontal clustered **ArmoredColumns**; front row gets **+50% health**.
- **Narrow-beam detection:** if the weapon is a piercing beam/railgun, the flock applies
  side-stepping offset vectors of **X ± 150px** to break lines.

### Elite Weapon Matrix
- **Boiled Napalm Eggs** — on bottom-edge or hull contact, instantiates a static
  `HazardArea` spanning **3 seconds**.
- **Magnetic Yolk Charges** — attractive force vector
  `F = G * (m1 * m2) / r^2` (`GameConstants.MagneticGravitationalConstant`).
- **Rooster Flak Shrapnel** — `OnDestroy` hook instantiates **8 radial feather projectiles
  at 45°** intervals.

### Weapon mod stacking (`WeaponInstance.RecomputeStats`)
- **Muzzle (Choke-Bore Lens):** `damageMultiplier 1.25`, `spreadAngleOffset -15`.
- **Magazine (Cryo-Yolk Stabilizer):** `cooldownMultiplier 1.10`, injects **Freeze**
  (−40% enemy move speed, **2.0s**).
- **Core (Supercharged Dynamo):** `IOnHitHandler` with **5%** probability to call
  `PlayerShip.RestoreShield(damageDealt * 0.05)`.

Defined in `ProjectSettings/TagManager.asset`; collisions configured in
`ProjectSettings/Physics2DSettings.asset`:

| Layer | Index | Collides with |
|---|---|---|
| PlayerShip | 12 | Enemy, EnemyProjectile, HazardArea, BossEntity |
| Enemy | 13 | PlayerShip, PlayerProjectile |
| PlayerProjectile | 14 | Enemy, BossEntity |
| EnemyProjectile | 15 | PlayerShip |
| HazardArea | 16 | PlayerShip (trigger) |
| BossEntity | 17 | PlayerShip, PlayerProjectile |

Projectiles never self-collide, so pooled fleets stay cheap.

## 5. Performance strategy

- `Application.targetFrameRate = 60` with `vSyncCount = 0` and `fixedDeltaTime = 1/60`.
  In production builds `Debug.unityLogger.logEnabled = false` and stack traces are disabled
  (`GameManager.ApplyProductionOptimizations`).
- **Object pooling** via `Pool<T>` (Stack-backed). Pools are prewarmed before combat
  (`ObjectPooler.Prewarm`) so combat allocates nothing; exhaustion grows by one instead of
  throwing.
- All movement uses `Rigidbody2D.MovePosition` with continuous collision detection.
- `SaveSystem` uses a dirty flag + 30s auto-save and flushes on
  `OnApplicationPause`/`OnApplicationQuit` so disk I/O never stalls the render thread.
  Writes are atomic (temp file + `File.Replace`).

## 6. Android build notes

- IL2CPP + ARM64, `minSdkVersion 29`, `targetSdkVersion 34`.
- `VIBRATE` (damage haptics) and `INTERNET` permissions declared.
- `supports-screens` excludes `smallScreens`; normal/large/xlarge enabled.
- Portrait-only (`screenOrientation: portrait`, autorotation disabled in PlayerSettings).
- Haptics honor `GameSettings.hapticsEnabled` / `damageHaptics` and can be disabled.

## 7. Save file

`Application.persistentDataPath/usr_profile.dat`

Schema (JSON, AES-256-CBC encrypted at rest):

```json
{
  "schemaVersion": 1,
  "profileId": "abc123...",
  "scrapIron": 0,
  "yolkCores": 0,
  "goldenFeathers": 0,
  "galaxiesCleared": 0,
  "highestTierReached": 0,
  "totalChickenKills": 0,
  "currentRunSeed": 0,
  "completedNodeIds": [],
  "unlockedMods": ["muzzle.choke_bore_lens", "magazine.cryo_yolk_stabilizer", "core.supercharged_dynamo"],
  "loadout": {
    "muzzleModId": "muzzle.choke_bore_lens",
    "magazineModId": "magazine.cryo_yolk_stabilizer",
    "coreModId": "core.supercharged_dynamo"
  },
  "settings": {
    "masterVolume": 1.0,
    "absoluteDragInput": true,
    "hapticsEnabled": true
  }
}
```

A tampered or corrupt file falls back to a fresh default profile — the game never crashes
over save data.
